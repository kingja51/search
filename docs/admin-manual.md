# 검색 관리자 화면 매뉴얼

> 접속 주소: `http://<서버주소>/search/adm/dic/word` (사용자 화면 오른쪽 위 **관리** 링크로도 진입)
> ⚠️ **현재 로그인/권한 기능이 없습니다** (Spring Security 추후 도입 예정).
> 내부망 등 신뢰 가능한 환경에서만 관리자 URL을 사용하세요.

---

## 1. 메뉴 구성

왼쪽 다크 사이드 메뉴에서 이동합니다.

| 구분 | 메뉴 | 주소 | 역할 |
|---|---|---|---|
| 사전 관리 | 단어사전 | `/adm/dic/word` | Nori 사용자 사전 (신조어·고유명사·복합명사) |
| | 동의어사전 | `/adm/dic/synonym` | 같은 그룹 = 서로 동의어 (검색 시 OR 확장) |
| | 금지어사전 | `/adm/dic/banned` | 검색 차단(BLOCK) / 검색식 제외(MASK) |
| | 추천 검색어 | `/adm/dic/recommend` | 사용자 화면 추천검색어 바 노출 |
| 운영 | 색인 관리 | `/adm/index` | 색인 현황·동기화·전체 재색인 |
| | 검색 통계 | `/adm/stats` | 검색량·인기/무결과 검색어 (Chart.js) |
| | 모니터 | `/adm/monitor` | 실시간 성능 지표 (5초 갱신) |

---

## 2. 사전 관리 공통

- 목록에서 **[활성/비활성]** 토글, **[삭제]**(확인창)를 사용합니다. 비활성 항목은 흐리게 표시되며 검색에 반영되지 않습니다.
- **등록·토글·삭제 즉시 반영**: 저장(커밋) 후 관련 캐시 비우기 + Nori 사전 리로드가 자동 수행됩니다. 재기동이 필요 없습니다.
- **중복 등록**은 "이미 등록된 항목입니다" 안내와 함께 거부됩니다.
- **[사전 리로드]** 버튼: SQL로 DB를 직접 수정한 경우에만 수동으로 누릅니다. (화면에서 변경했다면 자동)

### 2.1 단어사전

Nori 형태소 분석기가 모르는 단어를 등록합니다.

| 필드 | 설명 | 예 |
|---|---|---|
| 단어 * | 한 단어로 인식시킬 표기 | `아이폰15`, `고넷` |
| 분해형 | 복합명사의 분해 표기 (공백 구분). 비우면 단일어 | `아이폰 15` — 원형·분해형 모두 검색됨 |
| 품사 | NNG(일반명사) / NNP(고유명사) | 회사·인명·지명은 NNP |
| 메모 | 등록 사유 등 | |

> ⚠️ **단어사전 변경은 기존 색인에 자동 반영되지 않습니다.**
> 새 분석 결과를 기존 문서에 적용하려면 [색인 관리]에서 **전체 재색인**을 실행하세요.
> (검색어 분석에는 즉시 반영되므로, 재색인 전까지는 색인·검색 토큰이 어긋날 수 있습니다)

### 2.2 동의어사전

- **그룹 번호가 같은 단어들 = 서로 동의어**입니다. 어느 단어로 검색해도 그룹 전체가 OR로 확장됩니다.
  예) 그룹 1 = {휴대폰, 핸드폰, 스마트폰} → "휴대폰" 검색 시 셋 다 검색·강조
- 대표어(★)는 그룹의 기준 단어 표시용입니다(검색 동작은 동일).
- 새 그룹을 만들 때는 사용하지 않은 그룹 번호를 지정하면 됩니다.
- 재색인 불필요 — 동의어는 검색 시점에 확장됩니다.

### 2.3 금지어사전

| 유형 | 동작 |
|---|---|
| **BLOCK** | 검색어에 포함되면(부분 일치) 검색 자체를 차단하고 안내 문구 표시 |
| **MASK** | 검색은 허용하되 해당 단어만 검색식에서 조용히 제외 |

- 차단된 검색은 로그에 기록되며(is_blocked), 인기 검색어 집계에서 자동 제외됩니다.
- 결과내 재검색으로 우회할 수 없습니다(모든 검색어를 매 요청 재검사).

### 2.4 추천 검색어

- 사용자 화면 상단 파란 바에 노출됩니다. **순서**가 낮을수록 앞에 표시됩니다.
- **노출 시작일/종료일**을 지정하면 그 기간에만 노출됩니다(비우면 상시). 예: 채용 시즌 한정 키워드
- 노출 반영은 최대 10분(캐시) 이내입니다. 화면에서 등록/수정하면 즉시 반영됩니다.

## 3. 색인 관리 (`/adm/index`)

- **현황 카드**: 전체·도메인별(컨텐츠/파일/게시판/메뉴) 색인 문서 수
- **마지막 실행 결과**: 최근 동기화/재색인의 모드·건수·소요시간 (이번 기동 이후 기준)

| 버튼 | 동작 | 언제 사용 |
|---|---|---|
| **지금 동기화 (변경분만)** | 원본과 색인의 content_hash를 비교해 신규·변경·삭제만 처리 | 새 문서를 색인 스케줄 전에 급히 반영할 때 |
| **전체 재색인 (전량 재분석)** | 해시 무시, 모든 문서를 다시 형태소 분석 | **단어사전 변경 후**, 품사 설정(keep-pos) 변경 후 |

- 자동 스케줄: **매일 06:00 / 18:00** + 앱 기동 직후 1회
- 문서가 많으면 전체 재색인은 시간이 걸릴 수 있습니다(실행 중 화면 대기).

## 4. 검색 통계 (`/adm/stats`)

- 우측 상단에서 기간(최근 7/30/90일)을 선택합니다.
- **요약 카드**: 총 검색 / 무결과 검색 / 금지어 차단
- **차트**: 일별 검색량(14일) · 시간대별(0~23시) · 검색 대상별 분포(도넛) · 색인 카테고리 분포
- **인기 검색어 TOP 20**: 해당 기간 최다 검색어 (클릭 시 실제 검색 화면으로)
- **무결과 검색어 TOP 20** ★ 가장 유용한 리포트:
  사용자가 찾았지만 결과가 0건이던 검색어입니다. **사전 보강의 단서**로 활용하세요.

### 무결과 검색어 대응 워크플로

1. `/adm/stats`에서 무결과 검색어 확인 (예: "고객센터" 13회)
2. 원인 판단:
   - 표기 차이 → **동의어사전**에 그룹 등록 (예: 고객센터 = 콜센터 = 상담센터)
   - 신조어/복합명사가 잘게 쪼개짐 → **단어사전** 등록 + **전체 재색인**
   - 실제로 콘텐츠가 없음 → 콘텐츠 담당 부서에 전달
3. 등록 후 해당 검색어로 직접 검색해 결과 확인

## 5. 모니터 (`/adm/monitor`)

Micrometer(Prometheus) 메트릭을 5초 간격으로 시각화합니다. (외부 도구 불필요)

| 항목 | 의미 |
|---|---|
| 누적 검색 수 / 평균 응답 | 기동 이후 누적 (재기동 시 초기화) |
| 검색 처리량 | 초당 검색 수 추이 (최근 5분) |
| 평균 응답시간 | 폴링 구간별 평균. 범례 클릭으로 단계별(analyze/expand/fts/highlight) 표시 — **어느 단계가 느린지** 확인 |
| 캐시 히트율 | 사전·인기검색어 등 캐시 효율. 지속적으로 낮으면 TTL/구성 점검 |
| 색인 문서 수 | 도메인별 현재 색인량 |
| 배치 현황 | 색인 동기화·인기검색어 갱신의 실행 횟수·평균 소요 |

- 원시 메트릭은 관리 포트에서 확인: `http://<서버>:9090/actuator/prometheus`

## 6. 자주 하는 작업 빠른 참조

| 하고 싶은 것 | 방법 |
|---|---|
| 신조어가 검색 안 됨 | 단어사전 등록 → 색인 관리에서 **전체 재색인** |
| 비슷한 말도 같이 검색되게 | 동의어사전에 같은 그룹 번호로 등록 (재색인 불필요) |
| 특정 단어 검색 막기 | 금지어사전 BLOCK 등록 (즉시 적용) |
| 메인에 키워드 밀어주기 | 추천 검색어 등록 (순서·기간 지정) |
| 새 문서 바로 검색되게 | 색인 관리 → 지금 동기화 |
| SQL로 사전 고친 뒤 반영 | 사전 관리 화면의 [사전 리로드] 버튼 |
| 검색 품질 점검 | 검색 통계의 무결과 검색어 TOP 20 |
| 새 검색 대상(테이블) 추가 | [검색 VIEW 추가 가이드](add-search-source.md) 참조 |
