# 통합검색 사용자 매뉴얼

> 접속 주소: `http://<서버주소>/search/` (예: http://localhost:8080/search/)
> 이 문서는 사용자 화면 기준입니다. 관리자 기능은 별도 문서를 참조하세요.

---

## 1. 화면 구성

```
┌───────────────────────────────────────────────────────────────┐
│ [검색 대상 ▼] [ 검색어 입력창        ] [검색] [상세검색] ☐ 결과내 재검색 │  ← ① 검색 바
├───────────────────────────────────────────────────────────────┤
│ ■ 추천검색어  검색엔진  형태소분석  동의어사전 …                       │  ← ② 추천검색어 바
├───────────────────────────────────────────────────────────────┤
│        검색어 "OOO"에 대한 총 N건의 검색결과를 찾았습니다.              │  ← ③ 결과 건수
├────────────┬────────────────────────────────┬─────────────────┤
│ ④ 카테고리   │ ⑤ 검색 결과                      │ ⑥ 인기 검색어      │
│  통합검색    │   (검색 전에는 검색 기능 안내)       │    내가 찾은 검색어  │
│  컨텐츠      │                                │                 │
│  파일       │                                │                 │
│  게시판      │                                │                 │
│  메뉴       │                                │                 │
└────────────┴────────────────────────────────┴─────────────────┘
```

| 영역 | 설명 |
|---|---|
| ① 검색 바 | 검색 대상 선택 + 검색어 입력 + 상세검색 열기 + 결과내 재검색 체크 |
| ② 추천검색어 바 | 관리자가 등록한 추천 키워드 — 클릭하면 바로 검색됩니다 |
| ③ 결과 건수 | 현재 검색어의 전체 결과 수 |
| ④ 카테고리 | 검색 대상별 결과 건수 — 클릭하면 해당 대상만 봅니다 |
| ⑤ 결과 영역 | 검색 결과 목록 (검색 전에는 검색 기능 안내가 표시됩니다) |
| ⑥ 사이드 위젯 | 인기 검색어(기간 탭) + 내가 찾은 검색어(최근 1개월) |

---

## 2. 기본 검색

1. 검색창에 검색어를 입력하고 **검색** 버튼(또는 Enter)을 누릅니다.
2. 여러 단어를 띄어쓰기로 입력하면 기본적으로 **모든 단어가 포함된** 결과를 찾습니다. (AND)

### 검색어 처리 방식 (알아두면 좋은 것)

- **형태소 분석**: 검색어는 명사 중심으로 분석됩니다. "검색엔진을 만들자"로 검색해도
  조사·어미는 제외되고 핵심 단어(검색엔진, 검색, 엔진 등)로 검색됩니다.
- **동의어 자동 확장**: 등록된 동의어는 함께 검색됩니다.
  예: **휴대폰**으로 검색하면 **핸드폰**, **스마트폰**이 들어간 문서도 함께 나옵니다.
- **하이라이트**: 결과에서 검색어(동의어 포함)는 <mark>노란색</mark>으로 강조됩니다.
- **금지어**: 운영 정책상 차단된 단어가 포함되면 "검색할 수 없는 단어가 포함되어 있습니다"
  안내가 표시됩니다.

---

## 3. 검색 대상(카테고리) 선택

두 가지 방법이 있습니다.

- 검색 바 왼쪽의 **검색 대상 선택**(통합검색/컨텐츠/파일/게시판/메뉴) 후 검색
- 검색 후 왼쪽 **카테고리 메뉴**에서 클릭 (대상별 건수가 함께 표시됩니다)

| 대상 | 검색 범위 |
|---|---|
| 통합검색 | 아래 4개 대상 전체 — 대상별로 묶어 상위 10건씩 보여줍니다 |
| 컨텐츠 | 페이지·아티클의 제목과 본문 |
| 파일 | 첨부파일의 파일명과 본문 추출 텍스트 (pdf, hwp, docx 등) |
| 게시판 | 게시글 제목과 본문 (공지사항, FAQ 등) |
| 메뉴 | 사이트 메뉴 이름과 설명 — 메뉴 위치를 찾을 때 유용합니다 |

- **통합검색**에서 각 그룹의 결과가 10건을 넘으면 **"더보기 (N건)"** 버튼이 나타나며,
  클릭하면 해당 대상 탭으로 이동해 전체를 볼 수 있습니다.
- **개별 대상 탭**에서는 스크롤을 내리면 다음 결과가 자동으로 이어서 로드됩니다(무한스크롤).
  또한 결과 위에 **세부 카테고리 필터**(예: 게시판의 notice/faq, 파일의 pdf/hwp)가 표시됩니다.

## 4. 정렬

결과 상단의 버튼으로 전환합니다.

| 정렬 | 기준 |
|---|---|
| **정확도** (기본) | 검색어와의 관련도가 높은 순 |
| **최신순** | 문서 등록(수정)일이 최근인 순 |

## 5. 상세검색

검색 바의 **[상세검색]** 버튼을 누르면 패널이 열립니다.

### 5.1 기간 검색

- **기간 프리셋 버튼**: `전체` `실시간` `1일` `이번주` `이번달` — 클릭하면 시작일~종료일이 자동 입력됩니다.
  - 전체 = 기간 해제 · 실시간 = 오늘 · 1일 = 어제~오늘 · 이번주 = 월요일~오늘 · 이번달 = 1일~오늘
- **시작일~종료일 직접 지정**: 달력에서 날짜를 고른 뒤 **[조건 적용]**을 누릅니다.
- 기간이 적용 중이면 결과 상단에 `기간: 2026-07-01 ~ 2026-07-28` 배지가 표시됩니다.

### 5.2 AND / OR (다중 검색어 결합)

- **AND** (기본): 입력한 단어가 **모두** 포함된 문서만.  예) `검색 엔진` → 두 단어 모두 포함
- **OR**: 입력한 단어 중 **하나라도** 포함된 문서.  더 많은 결과를 보고 싶을 때 사용

### 5.3 결과내 재검색 (결과 좁혀 가기)

현재 검색 결과 **안에서** 추가 검색어로 범위를 좁힙니다. 두 가지 방법:

1. **검색 바 체크박스**: `☐ 결과내 재검색`을 체크한 상태로 새 검색어를 입력하고 검색
2. **상세검색 패널**: "결과 내 재검색" 입력란에 새 검색어 입력 후 [재검색]

- 적용된 조건은 결과 상단에 **칩(작은 태그)** 으로 표시되며, 칩의 **×** 를 누르면 그 조건만 제거됩니다.
- 재검색 조건은 최대 5개까지 누적됩니다.
- 체크박스를 **체크하지 않고** 새 검색어로 검색하면 이전 재검색 조건은 초기화됩니다(새 검색).

## 6. 검색 결과 읽는 법

결과 1건은 다음과 같이 표시됩니다.

```
동의어 사전 활용 가이드                            ← 제목 (클릭 시 원본으로 이동)
동의어 사전을 활용하면 휴대폰, 핸드폰, 스마트폰처럼…     ← 내용 발췌 (검색어 강조)
2026.07.27 · 기술 · 원본: /search/content/6        ← 등록일 · 카테고리 · 원본 링크
```

- **제목** 또는 **원본 링크**(초록색)를 클릭하면 원본 문서(컨텐츠/게시글/파일 상세)로 이동합니다.
- **내용**은 검색어 주변을 발췌해 보여주며, 검색어와 동의어가 강조됩니다.
- 파일 결과의 상세 화면에서는 파일 정보와 본문 미리보기를 볼 수 있습니다.

## 7. 검색어 도우미

| 기능 | 사용법 |
|---|---|
| **자동완성** | 검색창에 2글자 이상 입력하면 관련 제목이 추천됩니다. 항목 클릭 시 바로 검색 |
| **인기 검색어 (검색창)** | 빈 검색창을 클릭하면 인기 검색어 목록이 나타납니다 |
| **인기 검색어 (사이드)** | 오른쪽 위젯에서 기간 탭(전체/실시간/1일/이번주/이번달)별 TOP 10 확인 |
| **추천검색어** | 상단 파란 바의 키워드 — 관리자가 선정한 주제로 바로 검색 |
| **내가 찾은 검색어** | 오른쪽 위젯 — 내가 최근 1개월간 검색한 키워드 최대 10개 (본인 브라우저 기준) |

## 8. 자주 묻는 질문

**Q. 검색 결과가 나오지 않아요.**
- 단어를 더 짧게(핵심 명사만) 입력해 보세요. 예: "검색엔진 구축 방법" → "검색엔진"
- 상세검색의 OR로 바꾸면 더 넓게 검색됩니다.
- 기간 배지가 표시되어 있다면 상세검색에서 **전체**를 눌러 기간을 해제해 보세요.
- 결과내 재검색 칩이 남아 있다면 ×로 제거해 보세요.

**Q. 방금 등록한 문서가 검색되지 않아요.**
- 색인은 **매일 2회(06:00 / 18:00)** 자동 갱신됩니다. 갱신 전의 신규·수정 문서는 검색에
  반영되지 않을 수 있습니다. (급한 경우 관리자에게 색인 동기화를 요청하세요)

**Q. "검색할 수 없는 단어" 안내가 나와요.**
- 운영 정책상 차단된 단어가 포함된 경우입니다. 다른 표현으로 검색해 주세요.

**Q. 검색 URL을 공유할 수 있나요?**
- 네. 검색 조건(대상·정렬·기간·재검색 조건)이 모두 주소(URL)에 담기므로,
  주소를 복사해 공유하거나 북마크하면 같은 결과 화면이 열립니다.
