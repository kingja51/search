검색 기능 안내

검색어는 한국어 형태소 분석(명사 중심)으로 처리되며, 동의어 사전에 따라 자동 확장됩니다. (예: 휴대폰 = 핸드폰 = 스마트폰)

검색 연산자

연산자 설명 / 사용 예
AND (기본) 모든 검색어가 포함된 결과를 찾습니다. 예: 검색 엔진
OR 검색어 중 하나라도 포함되면 찾습니다. 상세검색 패널에서 선택합니다.

상세검색

결과내 재검색 현재 검색 결과 안에서 새 검색어로 좁혀 갑니다. 적용된 조건은 칩(chip)으로 표시되며 × 클릭으로 제거할 수 있습니다.
기간 검색 실시간(6시간) · 1일 · 이번주 · 이번달 버튼, 또는 상세검색에서 시작일~종료일을 직접 지정합니다.
정렬 정확도순(기본) / 최신순

편의 기능

자동완성 검색어를 2글자 이상 입력하면 관련 제목을 추천합니다.
하이라이트 검색어와 동의어가 결과에서 강조 표시됩니다.
인기·추천 검색어 인기 검색어는 최근 7일 검색 로그로 자동 집계되고, 추천 검색어는 관리자가 등록합니다.
